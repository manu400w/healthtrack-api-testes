# 🏥 HealthTrack API — Testes de Software

API REST desenvolvida em equipe para o **HealthTrack**, um sistema de organização de cuidados compartilhados.

O projeto foi desenvolvido com foco em **Qualidade de Software e Testes**, abrangendo desde a documentação dos requisitos até a elaboração e execução de estratégias de testes para a API e para a interface.

## 🎯 Sobre o projeto

O HealthTrack tem como objetivo centralizar informações relacionadas aos cuidados, permitindo a organização de compromissos, medicamentos, tarefas e anotações que podem ser compartilhados com pessoas autorizadas.

Além do desenvolvimento da API REST, o projeto conta com uma documentação completa na **Wiki**, contemplando diferentes etapas do processo de qualidade de software.

## 👥 Equipe

Projeto desenvolvido colaborativamente por uma equipe de estudantes de Ciência da Computação.

Cada integrante participou das etapas de desenvolvimento, documentação e/ou testes do projeto.

## 🧪 Qualidade e testes

O projeto aborda diferentes práticas de teste e qualidade, incluindo:

- Documentação de requisitos
- Histórias de usuário
- Requisitos funcionais
- Regras de negócio
- Plano de qualidade
- Análise e gerenciamento de riscos
- Métricas de qualidade
- Rastreabilidade
- Casos de teste
- Testes de API
- Testes de interface

## 🔎 Testes

### API

Foram realizados testes dos endpoints da API utilizando ferramentas de teste de API, verificando o comportamento das funcionalidades e suas respectivas respostas.

### Interface

Também foram realizados testes automatizados da interface, verificando o comportamento da aplicação durante a interação com seus elementos.

## ⚠️ Análise de riscos

O projeto contempla uma análise de riscos relacionada à qualidade do software, utilizando a abordagem **FMEA** para auxiliar na identificação e priorização de possíveis problemas.
